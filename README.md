# SpendSphere: Mapping the Hidden DNA of Consumer Spending

## Overview

SpendSphere is a **K-Means clustering project** that segments customers based on their purchasing behavior. The project uses customer demographics, purchase activity, ratings, and spending patterns to identify meaningful customer groups.

## Objectives

* Analyze customer spending behavior.
* Identify distinct customer segments using K-Means.
* Determine the optimal number of clusters using the Elbow Method and Silhouette Score.
* Generate actionable business insights from customer segments.

## Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

## Workflow

**Data Cleaning → EDA → Feature Selection → Scaling → Elbow Method → Silhouette Score → K-Means → Cluster Analysis**

## Key Insights

* Customer spending behavior varies across different segments.
* Customers with higher purchase activity can form distinct customer groups.
* Age alone does not fully explain spending behavior.
* Combining multiple behavioral features provides better customer segmentation.
* Clustering can support targeted marketing and personalized promotions.

## Conclusion

SpendSphere demonstrates how **unsupervised machine learning and K-Means clustering** can transform customer data into meaningful segments and support data-driven marketing and customer-retention strategies.
